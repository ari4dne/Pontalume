# Security policy

## Reporting a problem

Found something that could put BLEam users' privacy or security at risk?
Please **don't** open a public issue.
[Report it privately](https://github.com/ari4dne/BLEam/security/advisories/new) instead.
Only you and I can see the report, so the problem can be fixed before it's widely known.

For example, BLEam sending data off your PC.

**Already known, no need to report:** like most Bluetooth apps, BLEam's logs on your PC
include MAC addresses. The diagnostic export removes the ones it recognizes, but some may
get through, so please check an export before you share it.

English is easiest for me, but you're welcome to write in any language.

Code of conduct problems are reported the same way.

## Supported versions

Only the latest version of BLEam from the Microsoft Store gets fixes.
The Store updates apps automatically, so please make sure you're up to date before reporting.

## What to expect

BLEam is made by one person in their spare time, so I can't promise a timeline.
I read every report and reply as soon as I can.

Once a problem is fixed, the fix ships in a Store update and I publish a security advisory here.
If you'd like, you'll be credited in the advisory.
